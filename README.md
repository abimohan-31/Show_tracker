<section class="project-details">
  <h4>Technologies & Architecture</h4>

  <ul>
    <li>
      <strong>HTML5:</strong> Semantic structure for cinematic home views, show detail pages,
      and management interfaces.
    </li>

    <li>
      <strong>CSS3 (Vanilla):</strong> Custom cinema-inspired design system using CSS variables,
      Flexbox, Grid, and smooth animations for an immersive user experience.
    </li>

    <li>
      <strong>JavaScript (ES6+):</strong> Handles all application logic, dynamic rendering,
      filtering, searching, and state updates without external libraries.
    </li>

    <li>
      <strong>DOM Manipulation:</strong> Real-time rendering of show cards, filters, and UI updates.
    </li>

    <li>
      <strong>LocalStorage API:</strong> Persistent storage of watch status, ratings,
      and user preferences across sessions.
    </li>

    <li>
      <strong>JSON Data Model:</strong> Structured schema supporting movies and series,
      watch states, and ratings.
    </li>

    <li>
      <strong>Responsive Design:</strong> Mobile-first layout ensuring usability across
      desktops, tablets, and smartphones.
    </li>
  </ul>
</section>
